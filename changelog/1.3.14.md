# 1.3.14 (02/09/2026)

**Title:** CTS700 Nordic Modbus read stability + official manual links

**Tag:** [v1.3.14](https://github.com/master3395/veista-nilan/releases/tag/v1.3.14)  
**Author:** master3395

## What changed

- Serialize CTS700 Nordic Modbus hub calls with an asyncio lock so parallel entity polls do not overlap on Ethernet (reduces `unknown` / glance spinners / NaN)
- Sensor and number entities keep the last good reading when a poll returns `None` instead of clearing state to `unknown`
- Docs: [manuals.md](../docs/manuals.md) points to official Nilan download portals (no manufacturer PDFs in the repo)
- Docs: generic dual-path YAML + integration migration guide; site-specific to-do notes removed from the tree

## Operator notes

- Upgrade via HACS / git pull, then **reload the Nilan config entry** (or restart Home Assistant).
- If you also run YAML Modbus against the same TCP endpoint, prefer one active client where possible; this release only hardens the integration hub.

## Scope

`device_cts700_nordic.py`, `sensor.py`, `number.py`, `docs/manuals.md`, `docs/README.md`, `docs/cts700/README.md`, `to-do/` dual-path docs, `manifest.json`.
